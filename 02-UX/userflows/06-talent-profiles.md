# User Flow 6 — Talent Profiles

## Overview

This document defines how administrators manage approved talent profiles before they become available to clients.

---

# User Flow 6.1 — Create Talent Profile

## Main Flow

1. An approved candidate is selected.
2. The system creates a Talent Profile.
3. The profile is saved as unpublished.

---

# User Flow 6.2 — View Talent Profile

## Main Flow

1. Open Talent Profiles.
2. Select a profile.
3. View:
   - Personal information
   - Skills
   - Experience
   - Resume
   - Availability
   - Visibility status

---

# User Flow 6.3 — Edit Talent Profile

## Main Flow

1. Open a profile.
2. Select **Edit**.
3. Update information.
4. Save changes.

---

## Error Flows

### Validation Error

1. Invalid information is entered.
2. Validation errors are displayed.

---

# User Flow 6.4 — Publish Profile

## Main Flow

1. Open an unpublished profile.
2. Select **Publish**.
3. The profile becomes visible in the Client Workspace.

---

# User Flow 6.5 — Hide Profile

## Main Flow

1. Open a published profile.
2. Select **Hide**.
3. The profile is removed from client visibility.

---

# User Flow 6.6 — Archive Profile

## Main Flow

1. Open a profile.
2. Select **Archive**.
3. Confirm the action.
4. The profile moves to Archived Profiles.

---

## Alternative Flows

### Restore Profile

1. Open Archived Profiles.
2. Restore the profile.
3. The profile becomes active again.

---

## Postconditions

- Talent profiles accurately reflect their current visibility and lifecycle status.
